# 0001 Cache lantern schedules

> Short version: keep each lantern schedule in a cache.

## Decision

Keep each lantern schedule in the cache for 90 minutes.

Never cache the schedule of a lantern that is out.

## Install

Put the cache next to the lanterns, as the [guide](../guide.md#install) says.
